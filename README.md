# Simple Interest Calculator

A beginner-friendly project created as part of our micro-finance startup's transition from **SVN to Git**.  
This repository demonstrates the use of GitHub best practices for hosting open-source code.

---

## 📖 Project Overview
This project provides a simple Python script to calculate **Simple Interest (SI)** using the formula:
Simple Interest (SI) = (P × R × T) / 100

Where:  
- **P** = Principal Amount  
- **R** = Rate of Interest (annual, in %)  
- **T** = Time (in years)
